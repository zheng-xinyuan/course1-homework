Agent 是怎么接上 DeepSeek 的 HOW IT WORKS

Claude Code 内部有五个「模型名字」，实际只对应 DeepSeek 的两个模型，靠 7 个环境变量做映射：

接口地址
ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
鉴权
ANTHROPIC_AUTH_TOKEN=sk-****（密钥只存在本机用户环境变量，不进仓库）
主 / Opus / Sonnet
deepseek-v4-flash-vision-exp —— 复杂决策，会看图
Haiku / 子代理
deepseek-v4-flash —— 大量搜索读取，更便宜

三个验收动作 ACCEPTANCE

  • 读 —— 让它列出文件夹并总结里面的文件：确认它真能读到我本机的文件。
  • 跑 —— 让它写一个画图脚本并自己运行成功：确认它能写代码、还能真的执行。
  • 查 —— 让它联网查一条最新信息并写进 md：确认它能联网、并把结果落盘。

踩到的坑 GOTCHAS

  • Windows 的 PowerShell 默认执行策略是 Restricted，npm 会直接报「禁止运行脚本」， 需要先 Set-ExecutionPolicy -Scope CurrentUser RemoteSigned。
  • npm 官方源在国内很慢，先把源换成 registry.npmmirror.com 再装 CLI。
  • 模型名和价格会变，配置时要以操作当天的官方文档为准，不要照抄旧课件。
  • 密钥要从环境变量读，绝不能提交进 git 仓库。
一句话总结：这门课第一课要的不是「学会多少原理」，而是先拥有一个真的能干活的 Agent —— 装好、验收、上线，形成闭环。
